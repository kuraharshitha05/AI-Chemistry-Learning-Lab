# AI Chemistry Learning Lab

A simple interactive chemistry learning web app built with HTML, CSS, and JavaScript.

## Project Structure

AI-Chemistry-Learning-Lab/
├── index.html
├── style.css
├── script.js
├── pages/
│   ├── periodic-table.html
│   ├── molecules.html
│   ├── quiz.html
│   └── ai-tutor.html
├── assets/
│   ├── images/
│   └── models/
└── README.md

## App Features

- Home landing page with navigation links
- Periodic table overview page
- Molecules exploration page
- Interactive quiz page
- AI tutor page with simple chemistry responses

## How to Use

1. Open `index.html` in your browser.
2. Click through the navigation cards to explore each section.
3. Use the quiz page to test your chemistry knowledge.
4. Ask the AI tutor a question on the tutor page.

## Notes

- The `assets/images` and `assets/models` folders are ready for future content.
- This project uses plain web technologies and is easy to extend.
